# Comic List Web App

Fitur:
- Tambah, edit, hapus komik
- Pencarian judul
- Urut A-Z / Z-A
- Chapter terakhir dibaca
- Tanggal manual
- Penyimpanan browser via localStorage
- Service worker dasar untuk cache offline

Cara penggunaan:
1. Upload seluruh isi folder ke hosting HTTPS, misalnya GitHub Pages atau Netlify.
2. Buka URL HTTPS di Chrome Android.
3. Pilih menu browser > Tambahkan ke layar utama / Instal aplikasi.
4. Data tersimpan di browser perangkat.

Catatan:
- Data tidak otomatis tersinkronisasi antarperangkat.
- Menghapus data browser dapat menghapus koleksi.
- Backup/restore belum tersedia pada versi ini.
